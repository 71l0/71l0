# 🚀 Proyecto principal

<div align="center">

## 🔐 AnomalyWatch

### Intelligent Security Monitoring for Modern Infrastructure

</div>

**AnomalyWatch** es una propuesta de plataforma SaaS orientada a PyMEs y organizaciones que necesitan mejorar el monitoreo y análisis de eventos de seguridad sin disponer necesariamente de una infraestructura SIEM tradicional.

El sistema busca centralizar eventos provenientes de diferentes fuentes, detectar comportamientos anómalos y presentar la información mediante dashboards orientados tanto a perfiles técnicos como no técnicos.
